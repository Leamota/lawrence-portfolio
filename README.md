# Lawrence Egharevba — Portfolio Website

A responsive, static professional and academic portfolio based on the updated résumé and selected technical projects.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish using GitHub Pages
1. Create a new public repository (for example, `lawrence-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` folder to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Your website will be available at the GitHub Pages URL shown in Settings → Pages.

## Before publishing
- Confirm your employment and academic details are accurate.
- Add your verified LinkedIn/GitHub links when ready.
- Replace the résumé PDF in `assets/` whenever your résumé changes.
- The website intentionally does not claim peer-reviewed publications or link to unverified repositories.
- The website publishes your phone and FAU email, as requested for professional contact. You may remove the phone number for privacy.
- Google Fonts are used; if offline, the site falls back to Arial.
